# 日报中的功能更新

对用户有实际影响的功能上线时，在 `src/news_officer/release_notes.py` 添加稳定 ID、最早播报日期（北京时间）和两三句中文说明。只写已实现且随该版本部署的功能，不把 PR、计划或测试样例描述为已经推送的内容。普通依赖升级无需播报。

生产使用合并日报：功能说明出现在首份符合日期的定时早报开头，与播客摘要共用同一条消息。早报之后部署的更新会在下一份早报说明；没有新功能则不显示此栏目。没有播客摘要时仍可展示更新。补齐文字稿、临时查询和手动测试不会抢占这条公告。

SQLite 按功能 ID 将公告固定到一份定时日报，正文随不可变的 daily bundle 保存。失败重试继续发送同一份内容，不将预留视为发送成功，也不在下一日报重复播报。重启保留该状态。历史日报查询读取冻结的说明，不套用最新版本文案。若原日报长期发送失败，应修复/重试该任务，而不是悄悄将其当作已经通知。

部署验收：检查更新条目随源码上线、持久化数据库迁移正常、定时日报和补发场景测试通过。不要为验证功能而主动向群里另发通知。
